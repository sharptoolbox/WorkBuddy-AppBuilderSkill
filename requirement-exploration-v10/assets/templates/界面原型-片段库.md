## 片段 0　子条 1 引导句模板与形态枚举（**先看这里**）

> 子条 1 由**引导句 + ` ```html ` 原型块 + 图注**三件套构成。引导句不是可选项，也不是括号式装配说明 —— 它是读者在看不到渲染效果时唯一能读懂界面的入口。

### 片段 0-A　引导句句式（强制）

```text
### 9.x.1 UI 界面说明

```html
…
```

<p class="fig-cap">图 9-x　{界面名}界面原型（一句话关键规则）</p>
```

**四个必含要素**

| 要素 | 写法 | 禁止 |
|---|---|---|
| ① 形态标识 | `界面原型（列表维护形态）` —— 取值见 0-B 表 | 丢掉 `界面原型（）` 外壳；自造形态词 |
| ② 空间结构 | 「顶部工具栏…、中部列表…、底部分页…」 | **禁止写「N 项条件 / N 列」这类计数** |
| ③ 关键动作 | 「新增与编辑在弹窗内完成，弹窗内提供「保存草稿」「提交」两个独立按钮功能点（FUNC-24 / FUNC-25）」 | 只写否定式说明、不写正面动作；按钮不带编号 |
| ④ 设计意图 | 「列表展示上级组织与在职主体数，**停用前可评估影响范围**」 | 通篇只描述控件 |

> ⚠️ **标题必须写成 `### 9.x.1 UI 界面说明`**。写成 `### （1）UI 界面说明` 或 `#### UI 界面说明` 会产出**中文锚点**（实测 16 域文档会产生 112 处），目录与交叉引用全部失效，需整篇返工。

|---|---|---|---|

## 片段 6　自检清单（子条 1 写完后逐条过）

**A. 引导句（最易被忽略，逐条查）**

1. 子条标题是否为 `### 9.x.1 UI 界面说明`（**不是** `### （1）…`，**不是** `####`）？
2. ` ```html ` 围栏之前是否有引导句，且以 `界面原型（` 开头？
3. 括号内的形态标识是否取自片段 0-B（可带 `·` / `+` 后缀），有没有自造词？
4. 是否用「顶部 / 中部 / 底部」等**空间词**描述结构，而**没有**写「N 项条件 / N 列」这类计数？
5. 是否点明了**关键动作**（新增 / 编辑 / 停用 / 归档 / 保存草稿 / 提交 / 通过 / 驳回 / 视角切换 / 导出）并带 `FUNC-xx` / `B-APP-xx` / `Q-xx` 编号？
