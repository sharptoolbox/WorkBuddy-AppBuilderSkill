## 片段 5　常用零件速取

| 需要表达 | 写法 |
|---|---|
| 只读字段 | `<span class="ctl ro">值</span>` |
| 下拉框 | `<span class="ctl gr">值 ▾</span>` |
| 跳选框（对象引用） | `<span class="ctl psi">值<span class="bt">…</span></span>` |
| 日期 | `<span class="ctl">2026-09-15 📅</span>` |
| 多行文本域 | `<span class="ctl ta">（多行文本域）</span>` |
| 复选框 | `<span class="ck"><i class="on"></i>已勾选</span>` / `<span class="ck"><i></i>未勾选</span>` |
| 主 / 次 / 危险按钮 | `<span class="mbtn p">主</span>` / `<span class="mbtn s">次</span>` / `<span class="mbtn d">危险</span>`（行内加 `sm`） |
| 状态标签 | `.badge.b-succ` 已审核 / 已生效 / 已提交 · `.b-warn` 待审核 / 未提交 · `.b-danger` 已驳回 / 超期 · `.b-info` 进行中 · `.b-neutral` 草稿 / 已取消 / 已关闭 / 停用 |
| 明细内联输入 | `<input value="值">`（单元格内） |
| 金额右对齐 | `<td class="ra">` 或 `<th style="text-align:right">` |
| 汇总行 | `<tr class="sum"> … </tr>` |
| 关键规则提示 | `<div class="note info">…</div>` / `.note.warn` / `.note.ok` / `.note.err` |
| 图注 | `<p class="fig-cap">图 9-x　…</p>` |

## 片段 6　自检清单（子条 1 写完后逐条过）

1. 是否用 ` ```html ` 围栏（不是普通段落、不是表格、不是 ASCII 框图）？
2. 每个控件是否用了正确的 `.ctl` 变体（文本框 / 下拉 / 跳选框 / 日期 / 多行文本）？
3. 状态是否全部用 `.badge` 且颜色与第七部分字典值语义一致？
4. 按钮文案是否带功能点编号（`FUNC-xx` / `B-APP-xx` / `Q-xx`），不占编号的交互是否已标注？
5. 带审批的录入界面是否同时有「保存草稿」与「提交」两个按钮？
6. 列表类界面是否有工具栏 + 分页 + 弹窗示意；主从表是否有明细表格与汇总行；统计报表是否有合计行？
7. 原型中的字段 / 按钮是否都能对回子条 2 的界面元素表（同名、同文案）？
8. 业务编号示例是否符合 3.5 统一编号规则？
9. 是否已加 `<p class="fig-cap">` 图注？
10. 转换后的 HTML 中 `.mock` 数量 = 定义域数量，且不存在被转义的 `&lt;div class=&quot;mock`？
